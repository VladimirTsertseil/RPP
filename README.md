# Дневник питания и РПП

Небольшое статическое приложение для личного самонаблюдения. Работает без сервера, аккаунтов и внешних библиотек.

## Публикация на GitHub Pages

1. Создайте новый репозиторий GitHub (например, `rpp-diary`).
2. Загрузите `index.html` в корень репозитория и сделайте commit.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.
5. Откройте адрес, который покажет GitHub Pages.

## Данные и конфиденциальность

- Записи хранятся в `localStorage` браузера, **не в GitHub**.
- GitHub Pages — публичный сайт; код виден другим. Не добавляйте в репозиторий файлы с записями.
- Данные не синхронизируются между устройствами и браузерами. Для переноса используйте экспорт JSON и импорт на другом устройстве.
- Очистка данных сайта, приватный режим или смена браузера могут привести к потере записей. Регулярно экспортируйте резервную копию.
- Локальное хранение не является шифрованием: любой, кто имеет доступ к разблокированному браузеру или его профилю, потенциально может увидеть записи.

Инструмент не заменяет медицинскую помощь.
